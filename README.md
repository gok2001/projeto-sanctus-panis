# projeto-sanctus-panis
Projeto Integrador do Senai para um foodtruck

Sanctus Panis 🍔 

Sistema web para gerenciamento de pedidos de uma lanchonete/food truck, desenvolvido utilizando HTML, CSS, JavaScript, Node-RED e MySQL. 

📋 Sobre o Projeto 

O Sanctus Panis é uma aplicação web criada para permitir o cadastro de usuários, gerenciamento de produtos e realização de pedidos de forma simples e intuitiva.

CSS3

⚙️ Instalação 

1. Clone o repositório 

git clone https://github.com/seu-usuario/sanctus-panis.git 

2. Instale o Node-RED 

npm install -g --unsafe-perm node-red 

3. Inicie o Node-RED 

node-red 

Acesse: 

http://localhost:1880 

4. Configure o Banco de Dados 

Importe o arquivo: 

bd_sanctus-panis.sql 

para o MySQL. 

🛠 Componentes do Sistema 

Front-End 

HTML 

Responsável pela estrutura das páginas do sistema. 

CSS 

Responsável pela estilização e responsividade da interface. 

JavaScript 

Responsável pela lógica da aplicação e interação do usuário. 

Back-End 

Node-RED 

Gerencia as requisições HTTP e a comunicação com o banco de dados. 

Banco de Dados 

MySQL 

Armazena usuários, produtos, pedidos e demais informações do sistema.
